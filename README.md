A warm, funny family scene: Dad still sets a place for Mom at Sunday dinner — and the good plates never gather dust. One short scene, written to make a proud judge smile.

## Run it

```sh
python3 main.py
```

The program writes the scene to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the bounty gate (1–280 characters, one or two lines), re-reads it to confirm it matches byte for byte, and prints it.
